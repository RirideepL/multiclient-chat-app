# multiclient-chat-app
This project is one of my firsts in uni, a simple TCP/IP chat server and client implemented in Python, where the server listens for incoming client connections and facilitates communication between multiple clients. This is a simple, yet super fun chat system where multiple clients can connect to a server and chat with each other in real time.

Key Features:
Multithreading Magic: The server can juggle multiple clients at the same time without breaking a sweat. 🤹‍♂️

Socket Programming: I used Python's socket library to make the server and clients talk to each other over a local network (localhost). 🖥️💬

Broadcasting & Private Messaging: Send messages to everyone or just your friends, it's all possible here! 📡✨

Unique Usernames: No username duplicates allowed—gotta keep things neat! 📝

This project was a part of my second-year coursework (2023), where I dove into the world of network communication and socket programming. It was a blast learning how to set up real-time connections and troubleshoot networking quirks. Hope you enjoy exploring this project as much as I enjoyed building it !!
